# Security policy

Motus Solver is a static web app: no backend, no account, no data leaves the browser.

## Reporting a vulnerability

Please **do not open a public issue**. Report it privately through
[GitHub private vulnerability reporting](https://github.com/Indianarex/motus-solver/security/advisories/new)
with the steps to reproduce. You will get an answer as soon as possible.

## Scope

Only the latest version on the `main` branch is supported.
